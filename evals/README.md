# Evals

这些是**行为测试模板**，不是真实人物数据。

- `evals.json` 里的姓名、学校、DOI、ORCID、URL 都是占位符（`<DOI>`、`<ORCID>`、`<学校>` 等）。
- 运行前，请用你自己的**公开学者**案例替换占位符；不要把普通私人个体放进 eval。
- 建议每条 eval 跑 with-skill / baseline 两组，按 `assertions` 逐项打分。
- 真实运行记录放在 `evals/runs/`，已被 `.gitignore` 排除，不要提交。

## 八类场景

1. 富信息公开学者；
2. 中等信息（DOI+ORCID+学校页）；
3. 只有学生活动报道、无公开论文；
4. 普通人（负样本）；
5. 两篇公众号（一篇正文、一篇图片证书）；
6. 稀疏正样本（论文+ORCID，无 Education）；
7. 弱键（只给姓名）；
8. 导师反查（学院名录 → 教师主页“学生信息”栏）。

导师反查只用于核验目标与导师的关系；不记录、不比较、不输出其他学生姓名或方向。
