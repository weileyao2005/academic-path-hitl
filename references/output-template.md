# Output Template

> 本 skill 的输出是“核验台账”，不是“人物简介”。
> 每条事实都要带来源、级别、直接/推断；推断要写依据和缺口。

## 1. `case.md` 模板

```markdown
# Case: <目标代号>

## 0. Gate

- 对象类别：公开学者 / 拒绝（普通私人个体）
- 强键：<DOI / ORCID / 论文题名 / 导师+机构 / 官方名单>
- 输出模式：ledger / links-only
- 创建日期：YYYY-MM-DD

## 1. 已知事实

| # | 事实 | 来源 | 级别 | 直接/推断 | 状态 |
|---|---|---|---|---|---|
| 1 |  |  | A/B/C/D | direct/inferred | 已确认/待确认/已排除 |

## 2. 论文

| 年份 | 论文 | 期刊 | 位次 | DOI | 来源 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 3. 人提供的线索

| 时间 | 人提供的 | AI 判断 | 级别 | 更新到 case |
|---|---|---|---|---|
|  | 链接/截图/说法 | match/mismatch/uncertain | A/B/C/D | 是/否 |

## 4. 缺口

- 还差什么？
- 哪个事实只有推断，没有直接证据？
- 哪个来源被删除 / 抓不到？

## 5. 下一步

1. <具体动作：打开哪个链接 / 搜哪个词 / 问用户要哪个锚点>

- 哪些候选被排除，为什么？
```

## 2. `lead_check` 回复模板

```text
结论：match / mismatch / uncertain

依据：
1. <事实 1> — <来源>（A/B/C/D，直接/推断）
2. <事实 2> — ...
3. <事实 3> — ...

级别：A/B/C/D
缺口：<还差什么>
下一步：
1. <具体动作>
2. <具体动作>
3. <具体动作>
```

**规则**：

- `match` 至少 3 点吻合；`mismatch` 至少 1 个关键点冲突；其余 `uncertain`。
- 每一点都要带来源；没有来源的判断不算依据。
- 不要把“时间/方向/单位吻合”写成“名单确认”；除非有唯一标识。
- 不要说“我搜了微信”；说“根据你提供的链接/截图”。

## 3. `links-only` 输出模板

```text
以下是与 <目标/主题> 相关的公开学术来源，按类型列出；不做整合、不做评价。

论文 / DOI：
- <DOI / 链接>

ORCID：
- <链接>

机构 / 导师页：
- <链接>

学位论文 / 会议：
- <链接>

检索式（可自行复制）：
- <query 1>
- <query 2>
```

**规则**：

- 只给链接和检索式，不写“这个人怎么样”。
- 不给公示、家庭、高中、私生活链接。
- 不给“关于某个普通私人个体”的链接包。

## 4. 虚构示例（只演示格式，不含真实个人）

```markdown
# Case: 示例学者 A

## 0. Gate

- 对象类别：公开学者（有 2 篇公开论文）
- 强键：DOI 10.0000/example.2025.000001
- 输出模式：ledger

## 1. 已知事实

| # | 事实 | 来源 | 级别 | 直接/推断 | 状态 |
|---|---|---|---|---|---|
| 1 | 本科：某农业大学 某学院 2020–2024 | 某学院优秀毕业生页 | A | direct | 已确认 |
| 2 | 硕士：某大学 某学院 2024–2027 | ORCID Education | B | direct | 已确认 |
| 3 | 博士：某大学 某学院 2027 拟录取 | 某大学拟录取 PDF | A | inferred（名单无本硕院校） | 待闭环 |
| 4 | 第一作者论文 2 篇 | ORCID / DOI | B | direct | 已确认 |

## 4. 缺口

- 第 3 条只有“姓名+专业+时间”吻合，名单没有本硕院校；不能写成“名单确认”。
- 本科页面的原件抓取失败，只有搜索摘要；标 B。

## 5. 下一步

1. 打开 <某大学拟录取 PDF>，核对姓名+专业代码。
2. 搜 <导师+学院>，确认课题组。
3. 如果 ORCID 缺失，向用户要 ORCID 或本科页面。
```

## 5. 写作风格

- 用“事实 / 来源 / 级别 / 缺口”，不用“她很优秀 / 顶刊 / 全球前 2%”。
- 推断写“依据 + 缺口”，不写“应该是”。
- 不写人物简介；不写“成长故事”；不写评价。
- 中文为主；论文题名、期刊名保留英文原文。
